# CSV Data Process

## Functions

1. transfer .mat files to .csv files on a computer without MATLAB using the program 'MATDataProcess'
2. select variables to plot curves using the program 'PlotwithCSV'
3. merge the first row and the second row in your .csv files, you maybe need the program 'MergeHeader'
4. If you have .csv files divided and you want merge them by name, you can use the program 'MergeCSV'
5. cut the header or the tail of your csv files
